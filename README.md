### 🎫 Ticket Management System (TMS) — Enterprise IT Support & Ticketing Platform

`Next.js 16` `React 19` `TypeScript` `NestJS` `PostgreSQL` `Drizzle ORM` `Better Auth` `Swagger/OpenAPI` `RBAC` `Nx Monorepo`

An enterprise IT service desk platform developed for Muktinath Krishi Company to digitize
ticket submission, triage, assignment, and resolution workflows across multiple companies,
departments, and organizational roles.

- Developed the frontend using **Next.js App Router, React 19 and TypeScript**, building a
  structured enterprise dashboard for managing tickets, categories, tags, users, companies,
  and departments.
- Helped build the backend with **NestJS and PostgreSQL using Drizzle ORM**, modeling tickets,
  comments, attachments, activity events, categories, tags, companies, and departments with
  full relational integrity.
- Designed a complete **ticket lifecycle** — creation, status and priority transitions,
  assignment, resolution, closure, threaded comments with internal staff-only notes, file
  attachments, and an immutable audit trail of ticket events.
- Implemented **RBAC using Better Auth access control**, defining a granular permission matrix
  across tickets, users, comments, attachments, categories, tags, analytics, and sessions,
  enforced through custom NestJS guards and decorators.
